# 会话与工作区

工作区是会话所使用的目录，不是权限隔离容器。启动时应用从 Pi 保存的会话发现工作区，所以之前在其他目录的会话也可能出现。

## 常用操作

- 在侧栏选择工作区与历史会话，或新建会话。
- 添加工作区时，环境支持则使用系统目录选择器；SSH 等环境可用内置目录浏览器。
- 从侧栏移除工作区**不删除实际文件或会话**；需要时可再次手动添加。
- 工作区记录和附件存放在 Pi 数据目录的 `pi-web/` 下；自定义数据根目录见[配置参考](./reference)。不要为了恢复侧栏而删除整个 Pi 数据目录。

## 切换、刷新和重启的差异

| 操作 | 会发生什么 |
| --- | --- |
| 切换聊天、工作区或新建聊天 | 原聊天继续后台运行，返回时恢复输出、历史和待处理插件交互 |
| 暂停当前聊天 | 只影响选中聊天，不是停止服务；见[对话控制](./conversation) |
| 刷新网页 | 不是重载后端；文件/工具标签布局会重置，终端不能依赖刷新恢复 |
| 停止或重启 Pi 服务 | 内存会话实例及后台任务结束，终端进程不跨重启保留；保存的历史不等于仍在运行的任务 |

其他工作区的聊天使用 Pi SDK，加载该工作区的技能和项目上下文。已启用 Web 插件的 Pi 入口显式加载，其他普通扩展不自动继承主桥接环境；不要假设所有聊天的扩展环境完全相同。

多个聊天可能同时操作同一个工作树。执行 Git 写操作前确认所有相关聊天空闲，并检查变更来源，不能把文件列表当成“仅由当前聊天产生”。

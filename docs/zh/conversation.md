# 对话控制与附件

对话展示 Markdown、流式回复、可展开的推理和工具调用、Token 用量与逐轮轨迹。可切换当前模型和思考级别；具体可用模型依赖你的[配置与认证](./configuration)。

## 暂停与继续

运行中右下角是暂停按钮，暂停会中止当前请求。暂停后清空输入框可使用「继续」；刷新或重开会话后仍支持恢复符合条件的暂停任务。

继续是隐藏的宿主控制动作，不新增用户消息：模型根据原任务、已有工具结果和部分回复发起**新请求**，不是从网络中断的同一个 token 原位接续。正在运行、已经完成或存在待处理交互的任务不能使用通用继续。

计划模式是插件能力，不是所有聊天的固有模式。它负责提问、审批、修订和预览。需要重新审批的计划必须重新批准；**历史批准不会自动授权新执行**。有待处理卡片时先处理交互，不要用通用继续绕过。

## 附件

- 通过选择、拖放或粘贴添加；每次最多 **20 个文件**，每个不超过 **20 MB**。
- 图片有预览，也会作为 Pi 图片内容发送。是否能处理图片还取决于模型输入类型。
- 不要上传 API 密钥、认证文件、私钥或无权提供的数据。发送给模型不等于“只在本地处理”，需遵守提供方的数据政策。

暂停只影响当前聊天；关闭页面、切换聊天与停止服务的区别见[会话指南](./sessions)。

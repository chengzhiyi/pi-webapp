# 对话

本页涵盖输入框和对话视图里的一切：发送消息、添加附件、斜杠指令、Pi 忙碌时排队发送、暂停，以及选择模型。

## 发送消息

在底部的输入框里输入，按 **Enter** 发送，按 **Shift+Enter** 换行。对话会渲染 Markdown 和代码块（每个代码块都有 **复制代码**），代理写出的工作区文件链接会在[文件工具](./workspace-tools#files)里打开预览。

每条回复下面，**复制回复** 复制文字，**用量** 显示这条回复用了多少 token。

右上角的小标记在页面与服务保持连接时显示 **已连接**，连接丢失时显示 **已断开**。侧栏里每个会话旁边会显示 **运行中** 或 **空闲**。

## 看懂代理做了什么

Pi 的工作过程会夹在你的消息和它的回答之间：

- **工具调用** 会折叠成一行，例如 **1 次工具调用**。点击它可以看到每次调用和它的结果。
- 会暴露推理过程的模型，其 **思考** 内容显示为可展开的一行。

![展开工具调用后的对话](/images/zh/tool-call-expanded.png)

想按轮次查看，可以在对话顶部从 **对话** 切换到 **轨迹**。它按顺序列出每条用户消息、每次工具调用和每条助手回复，并配有一条显示时间花在哪里的时间线，以及每次调用的详情（输入参数、输出、缓存读取和缓存写入 token，还有时长）。可以用搜索框筛选，也可以选择 **按事件顺序排列** 或 **按记录时间排列**。

![“轨迹”标签页](/images/zh/trajectory.png)

## 添加文件和图片

| 方式 | 说明 |
| --- | --- |
| **+** 按钮，再选 **添加 → 文件** | 打开系统的文件选择器。 |
| 把文件拖到页面上 | 会出现 **松开以上传文件** 的提示层。 |
| 粘贴 | 从剪贴板粘贴文件或截图即可添加。 |

一条消息最多可以添加 **20 个文件**，每个都不能为空，且不超过 **20 MB**。图片（PNG、JPEG、GIF 和 WebP）会有预览，并以图片形式发给模型，前提是该模型支持图片输入。你可以在[模型与提供方](./models#edit-a-providers-models)里标注某个模型接受的输入类型。

::: warning 附件会发给你的模型提供方
不要附加 API Key、凭据文件、私钥，也不要附加你无权分享的数据。附件内容会发送给你选定的提供方，适用它的数据政策。
:::

## 斜杠指令和 + 菜单 {#slash-commands}

在输入框的第一个字符输入 `/`，或者点击 **+**，就会打开指令菜单。用方向键移动，用 **Enter** 或 **Tab** 选中，用 **Esc** 关闭。

菜单里始终有：

- **压缩**：压缩当前会话的历史，腾出上下文。
- **模型**：为本会话选择模型。
- **新会话**：在当前工作区里新建一个会话。

它还会列出你已安装的扩展提供的指令，以及 Pi 在你的机器上找到的每个技能对应的一条 `skill:` 条目（[包、技能与插件](./extensions)）。

斜杠指令只能在 Pi 空闲时运行。Pi 工作期间你会看到 **运行中不执行斜杠指令，请等待当前回复结束**，排队的消息也不能以 `/` 开头。

## Pi 工作时继续发送

不必等回复结束。Pi 工作时就可以输入下一条消息：

- **Enter** 把它加入 **待处理提示词** 队列，Pi 会在当前任务结束后处理。
- **Ctrl+Enter**（macOS 上是 **Cmd+Enter**）则把它作为 **引导** 发送：它会在 Pi 的下一个可处理的时刻送达，不会中断正在运行的工具。

每条排队的消息都有 **编辑**、**删除** 和 **发送（引导）**。编辑时会保留附件；**保存修改** 或 **取消编辑** 可以结束编辑。不支持调整顺序。

需要知道的几点：

- 队列保存在服务的内存里。服务重启后队列会丢失；Pi 已经接收的消息也不能再编辑或撤回。
- 最多同时排 50 条，每条最长 32,000 个字符。

## 暂停与继续 {#pause-and-continue}

Pi 工作时，发送按钮会变成 **暂停执行**。暂停会停止当前的执行，并保留已有进度。它只影响那一个会话，不影响其他会话，也不影响服务。

已暂停、输入框为空的会话会显示 **继续执行**。继续会向模型发起一个**新的请求**，带上原来的任务、目前为止的工具结果和部分回复，而不是接着恢复那条被打断的网络流。排队的消息要等继续执行之后才处理，对应的提示是 **已暂停，继续后处理**。

仍在运行的会话、已经正常结束的会话，以及还有交互在等你回答的会话，都不能继续执行。请先回答或关闭那个交互。

## 选择模型与推理强度

打开输入框右下角的模型选择器，选 **模型**，再从你已连接的提供方里选。这个选择只作用于当前会话。

对支持的模型，选择器还会提供 **推理强度**：**关闭**、**极低**、**低**、**中**、**高** 或 **极高**。不支持推理的模型不会显示这个控件。

如果没有可用模型，输入框会提示 **先连接模型，再开始对话**，并带一个 **配置模型** 按钮。见[模型与提供方](./models)。

## 键盘快捷键一览

| 按键 | 位置 | 作用 |
| --- | --- | --- |
| Enter | 输入框 | 发送（Pi 工作时则排队） |
| Shift+Enter | 输入框 | 换行 |
| Ctrl/Cmd+Enter | 输入框，Pi 工作时 | 作为引导发送 |
| 开头输入 `/` | 输入框 | 打开指令菜单 |
| 方向键、Enter 或 Tab、Esc | 指令菜单 | 移动、选中、关闭 |

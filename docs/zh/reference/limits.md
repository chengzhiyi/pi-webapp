# 限制

本页汇总你可能遇到的大小和数量限制，帮你分清这是限制还是缺陷。

| 方面 | 限制 |
| --- | --- |
| **附件** | 每条消息最多 20 个文件，每个都不能为空，且最大 20 MB。 |
| **排队的消息** | 同时最多 50 条，每条最长 32,000 个字符，包括附件在内总共 64 MB。排队的消息不能以 `/` 开头。 |
| **文件预览** | 每个文件夹最多列出 1,000 项；文本最大 512 KB 和 10,000 行；图片最大 8 MB。 |
| **终端** | 每个会话 8 个、整个服务 32 个；2,000 行回滚内容；断开的浏览器会为它保留终端 5 分钟。 |
| **Git 面板** | 最多列出 1,000 个改动文件；超过 512 KB 或 10,000 行的差异只显示提示；历史每次加载 50 个提交。读取命令 10 秒超时，写入 30 秒超时。 |
| **会话名称** | 最多 120 个字符。 |
| **自定义提供方表单** | 名称最多 100 个字符，提供方 ID 最多 64，模型 ID 最多 200，API 地址最多 2,048。API Key 输入框最多接受 16,384 个字符。 |
| **代理画的图** | Pi 的画图工具每张图最多 30 个形状和 60 条连线，每个标签最长 500 个字符。 |
| **启动与关闭** | 启动大约 60 秒后放弃。`pi-webapp stop` 最多等大约 40 秒，`stop --force` 在 5 秒后改为直接结束进程。更新继续之前，插件视图必须在大约 15 秒内确认保存。 |

Pi 和你的模型提供方有它们自己的限制，比如上下文窗口大小和速率限制，这里没有列出。

# 术语表

本页解释指南里用到的术语，按主题分组，括号里附上英文原词，方便你对照界面和英文文档。

## 基本概念

**Pi。** pi-webapp 所服务的编程代理。它的包名是 `@earendil-works/pi-coding-agent`。

**代理（Agent）。** 调用模型，并使用工具读文件、改文件、运行命令来完成你请求的程序。在 pi-webapp 里指的就是 Pi。

**Pi SDK。** 作为库使用的 Pi。pi-webapp 的 npm 包固定使用它测试过的那一个确切 SDK 版本。

**会话（Session）。** 在某个工作区里和 Pi 的一次已保存的对话，以文件形式存放在 `sessions/` 下。

**工作区（Workspace）。** 一个项目目录，代理从这里开始工作，会话也按它分组。不是安全边界。

**轮次（Turn）。** 一条用户消息，以及 Pi 针对它所做的全部事情。

**工具调用（Tool call）。** 代理做的一次动作，比如读一个文件或运行一条命令。在对话里折叠显示，并列在“轨迹”标签页里。

**轨迹（Trajectory）。** 列出一个会话里每条消息、每次工具调用和每条回复，并带有耗时和 token 细节的标签页。

**模型提供方（Model provider）。** 托管模型的公司或服务器：Anthropic、OpenAI、你自己的网关。在 **Pi 设置 → 模型** 里连接。

## 运行与连接

**服务（Service）。** 在本地为页面提供内容并驱动 Pi 的程序，它只监听 `127.0.0.1`。

**后台启动器（Background launcher）。** `pi-webapp` 命令，以及它在你关掉终端之后仍保持运行的那个服务。也叫 Web 启动器。

**地址（Address）。** 启动器打印出的 URL，形如 `http://127.0.0.1:52395/#<token>`：你的机器、一个随机端口，加上访问令牌。

**访问令牌（Access token）。** 地址里 `#` 之后的那串随机秘密。拿到完整地址的人就能使用你的服务。见[安全与隐私](../security)。

**数据目录（Data folder）。** Pi 的目录（默认 `~/.pi/agent`），里面有你的会话、凭据、设置，以及 pi-webapp 自己的 `pi-web/` 状态。见[文件与目录](./files)。

**外壳（Shell，桌面版）。** 安装好的桌面应用本身，与它所运行的 pi-webapp 版本相区分。

**业务包（Business package）。** 在桌面应用里，运行在应用外壳内部的 pi-webapp 版本。它的更新与外壳分开。见[桌面版](../desktop)。

**交接（Handoff）。** 把一个正在运行的共享服务移交给当前桌面应用的启动器，同时不改变它的地址。它会等会话空闲，并且从不强制停止。

## 对话里的操作

**暂停执行 / 继续执行（Pause / Continue）。** 暂停执行会停下一个会话当前的执行并保留已有进度；继续执行会发起一个新的请求，接着它往下做。见[对话](../conversation#pause-and-continue)。

**排队（Queue）。** 你在 Pi 工作时发送的消息；Pi 会在当前任务结束后处理它们。见[对话](../conversation)。

**引导（Steer）。** 给一个正在工作的 Pi 发消息，让它在下一个可处理的时刻收到，而不必等任务结束。使用 **Ctrl/Cmd+Enter**。

**压缩（Compact）。** 一个缩短会话历史、腾出上下文的指令。可以从 **+** 菜单或用 `/compact` 运行。

## 扩展内容

**包（Package）。** 从 npm、Git 或目录安装的一组扩展和技能。

**扩展（Extension）。** 给 Pi 增加能力的代码，比如指令和工具。见[包、技能与插件](../extensions)。

**技能（Skill）。** 一个 `SKILL.md` 文件或一个目录，里面是 Pi 可以为某个任务加载的指引。技能以 `skill:<名称>` 指令的形式出现。

**插件（Plugin）。** pi-webapp 里有自己界面的功能：内置的文件、终端和 Git 工具，以及 Excalidraw 这类可选工具。在侧栏的 **插件** 下管理。

**托管插件（Hosted plugin）。** 下载后运行在自己的进程和浏览器框架里的那类插件，比如 Excalidraw。这个词会出现在一些日志和消息里。

## 更新

**稳定版 / 体验版（Stable / Preview）。** 更新选项。**稳定版** 只跟随 `latest`；**体验版** 跟随 npm 的 `latest` 和 `alpha` 里较新的那个。见[更新](../updates#channels)。

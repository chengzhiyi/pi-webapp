# 模型、包与技能

## 模型与认证

打开「设置 → 模型」管理提供方、登录与模型。可添加模型，编辑名称、上下文窗口、输出 token 上限和输入类型，或恢复内置模型默认参数；写入 Pi 的 `models.json`。当前对话的模型和思考级别在对话界面选择。

网页登录会打开提供方授权页，无法回调时按提示手动输入授权码。提供方认证可在此移除。凭据存放在 Pi 本机 `auth.json`，不会返回浏览器；不要把该文件用于排障附件。模型服务可能有使用费用，由你的提供方决定。

## 包、扩展、技能和 Web 插件不是一回事

| 名称 | 用途与入口 |
| --- | --- |
| Pi 包 | 可同时包含扩展和技能；在「设置 → 包与扩展」添加 npm、Git 或本地来源 |
| Pi 扩展 | Pi 的运行时能力；本地扩展也可单独加载，是否在其他工作区会话加载取决于宿主隔离规则 |
| 技能 | 被发现和加载的任务指导；在「设置 → 技能」检查或手动配置 `SKILL.md` 文件/目录 |
| Web 插件 | 为 Web 提供交互和面板；内置 Git/文件/终端/手绘图在侧栏「插件」管理，外部运行时仍在「包与扩展」管理 |

内置插件的开关全局持久化，所有聊天空闲时才可切换；停用会关闭相关标签并阻止后端请求。终端停用需确认，并结束服务全部终端。**安装包不等于启用/停用内置插件**；外部插件不提供只隐藏 UI 的假开关。

## 手绘图

右侧工作台选择「手绘图」，或在对话中说“画一个登录流程，包含失败重试”。Agent 通过绘图工具生成候选，点击卡片「打开编辑」，预览并接受后可手工修改。保存为工作区内的 `.excalidraw` 文件，可另存、导入、下载源文件和导出白底/透明底 PNG。改图候选需要再次接受；修订或文件冲突不会强制覆盖。

仅嵌入本地编辑器，不连接 Excalidraw 云服务；无模型仍可手改。浏览器备份不代替文件保存。首期不支持图片、外链、多人协作或无浏览器 PNG 渲染。更多边界见 [Diagrams](../diagrams.md)。更新后须先重建/重启后端，不能只刷新网页。

## 何时重载

包/扩展配置变化后遵循界面反馈，等待聊天空闲再重载，避免打断任务。不要把刷新网页当成后端扩展更新。源码开发时重建后重启启动器；使用 `pi -e .` 时重建后在 Pi 中 `/reload` 再 `/web`。详见[更新](./updates)与[开发资料](./resources)。

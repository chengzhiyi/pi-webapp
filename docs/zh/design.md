# 用 OpenPencil 做 UI 设计

本页说明如何安装可选的 OpenPencil 插件、让 Pi 设计界面、手动修改、控制 Pi 能改哪些内容，以及把设计稿保存进项目。

OpenPencil 是官方插件，基于开源设计编辑器 [OpenPencil](https://github.com/open-pencil/open-pencil)，**不随应用内置，也不会自动安装**。设计稿是 `.fig` 文件。Pi 直接修改设计稿：它的改动会在画布上即时出现，你可以撤销最近的一次。编辑器在你的浏览器里本地运行，不需要账号。插件不包含 OpenPencil 自带的 AI 对话，这件事由 Pi 用你连接的模型来做。

::: info 新功能
OpenPencil 还没有进入稳定版。见更新日志里的[未发布](./changelog#unreleased)部分。
:::

## 1. 安装并启用插件

1. 在侧栏点击 **插件**。
2. 在 **官方插件** 下找到 **OpenPencil（官方）**（状态显示 **未安装 · 未启用**），点击 **下载**。
3. 等状态变成 **已安装 · 未启用** 并出现版本号。这需要能访问 npm。安装包里带着完整的编辑器、渲染引擎和字体，所以比 Excalidraw 大。
4. 打开这一行右侧的开关，状态变成 **已安装 · 已启用**。

启用需要所有会话都处于空闲。点击这一行可以看到详情：包名（`@chengzhiyi/pi-pencil`）、已安装的版本、**检查更新** 和 **卸载**。OpenPencil 不需要其他配置，但需要浏览器支持 WebAssembly，目前所有主流浏览器都支持。

## 2. 打开编辑器

在对话里打开工具面板，开始页上会多出一个 **OpenPencil** 入口（**UI 设计**）。它会打开工作区里最近的设计稿；如果还没有，就打开一块空白画布：随便画点什么，它就成为一个名为 **未命名** 的设计稿。

左侧面板列出工作区里的设计稿，可以在它们之间切换或重命名。它的文件菜单里有：

| 菜单项 | 作用 |
| --- | --- |
| **新建设计** | 新建另一个设计稿。 |
| **保存为 .fig** | 把设计稿写进工作区（见[保存](#save)）。 |
| **在新标签页中打开** | 在单独的编辑器标签页里打开当前设计稿，可以像其他工具一样分屏或全屏。 |

## 3. 让 Pi 设计

在正常的对话里描述你想要的东西，不需要指定工具：

```text
设计一个手机登录页：邮箱和密码输入框、一个主要的登录按钮，以及“忘记密码？”链接。
```

Pi 会先读 OpenPencil 的设计指南，查看当前设计稿，再把修改作为一批带类型的操作（创建、修改、删除）发出来，而不是代码。修改会立即生效：

- 被修改的画框会在你的画布上被选中并移到视野里。
- 弹出提示 **Agent 已修改：** 加上这次修改的标题，并带一个 **撤销** 按钮。在你之后再动手编辑之前，都可以撤销。
- Pi 会拿到它修改部分的渲染图，可以自己检查效果，并在下一轮里修正。

可以继续在对话里提修改（“按钮改成通栏”、“加一个深色版本”）。如果在 Pi 上次查看之后你又改过设计稿，Pi 的修改会被拒绝，它要先重新读取设计稿，所以不会悄悄覆盖你的改动。

## 4. 控制 Pi 能改什么 {#agent-access}

右侧面板的 **Agent** 标签页列出 Pi 最近的修改，每条带有修订号、包含的操作数和时间。最近的一条带 **撤销** 按钮，已撤销的会标为 **已撤销**。

在 **Agent 权限** 下，先在画布或 **图层** 里选中图层，然后：

| 按钮 | 作用 |
| --- | --- |
| **锁定** / **解锁** | Pi 不能修改被锁定的图层，对它们的修改会被拒绝。 |
| **仅限所选图层** | Pi 只能修改选中的图层及其内部内容。 |
| **取消限制** | 解除上面的限制。 |

撤销、保存、锁定和限制范围都只能由你来做：Pi 没有对应的工具。

## 5. 手动编辑

画布就是 OpenPencil 自己的编辑器：画框、形状、钢笔、文字、自动布局、组件、布尔运算、页面和图层。右侧面板顶部是 **预览** 和 **保存** 按钮，下面是这些标签页：

- **设计**：所选图层的属性，也可以导出为 PNG、JPG、WebP 或 SVG。
- **代码**：把所选内容转成 JSX、React + Tailwind 或 HTML。
- **Agent**：Pi 的修改以及它能改哪些内容（见[上文](#agent-access)）。
- **Lint**：设计检查。

**预览**（macOS 上是 ⌥⌘↩）会在画布上运行设计稿：编辑界面隐藏，动画填充开始播放，带行为的组件（按钮、开关、滑块、标签页、输入框等）变成可以操作的控件。**重置** 让它们重新开始，按 Esc 退出。

主题和语言跟随 **Pi 设置 → 通用设置**。

## 6. 保存 {#save}

你和 Pi 的修改在编辑过程中都会由服务保存成修订版本。要在项目里得到一个文件，点击 **保存**（或文件菜单里的 **保存为 .fig**）。第一次保存会写入工作区里的 `designs/<标题>.fig`，必要时创建 `designs/` 文件夹；之后的保存写回同一个文件。然后像其他文件一样在 [Git 面板](./workspace-tools#git)里提交。

保存前会先核对文件内容。如果上次保存之后磁盘上的 `.fig` 文件被改过，这次保存会被拒绝，而不会覆盖那次修改。

## 限制与须知

- 单个 `.fig` 文件最大 64 MB。
- 停用或卸载插件不会删除工作区里的 `.fig` 文件。
- 插件会自动更新，打开着的编辑器会推迟版本切换（[官方插件](./extensions#official-plugins)）。
- 如果停止服务时还有编辑器处于打开且未保存的状态，`pi-webapp stop` 可能会被拒绝。见[排错](./troubleshooting#stop-is-refused-because-a-plugin-view-has-not-saved)。
- 这个插件早期的预览版叫 **Pencil**，那时 Pi 的修改需要你确认。用它做的设计稿里可能还留着当时的提案，会显示为 **旧版提案**，带 **接受** 和 **拒绝** 按钮。

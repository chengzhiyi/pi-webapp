# 更新日志

每个版本新增了什么，最新的在最前面。你正在运行的版本可以在 **Pi 设置 → 通用设置** 里查看，桌面构建号在 **pi → 关于 pi** 里查看。

pi-webapp 有两种发布方式。npm 包（也就是 Web 启动器，以及桌面应用里运行的服务）每次发布都会更新，在两者里点 **升级并重启** 都能装上，详见[更新](./updates)。桌面应用的安装包更新得没那么频繁。下面每一条要么是一个桌面构建，要么是一个带有重要变化的 npm 版本，内容涵盖自上一条以来的全部变化。**未发布** 列出的是[体验版](./updates#channels)里已有、但还没有进入任何稳定版的内容。

## 未发布 {#unreleased}

### 亮点

- **悬浮输入框。** 工具面板全屏、挡住对话时，输入框会悬浮在面板上方。它和平时的输入框共用草稿、附件、队列和斜杠指令。可以收起成一个显示 Pi 当前状态的图标，拖到任意位置，或用 ⌘/Ctrl+J 打开和收起。从这里发出的消息会告诉 Pi 你正在看哪个标签页；在文件浏览器里，还会带上打开的文件和选中的行。Pi 工作时它显示进度，结束后显示回复；展开后可以查看对话，或处理等待你确认的操作。
- **Pi 可以使用你的终端。** 让 Pi 在某个终端标签页里运行命令（“在这个终端里跑一下测试”）。它可以自行读取终端最近的输出，但每条要输入的命令都会先展示给你，等你选择 **允许** 或 **拒绝**。详见[终端](./workspace-tools#terminal)。

### 改进与修复

- 已经没有任何地方会启动的旧更新，会在启动约一分钟后自动删除，每个大约占 400 MB。只删除没在运行、没被选中、并且超过 24 小时的版本；更新进行中时不会删除任何东西。
- **Pencil 插件（可选）。** 基于 OpenPencil 的 UI 设计，从 **插件** 页面安装。你在工作区里编辑 `.fig` 设计稿，Pi 提出修改，由你接受或拒绝。Pencil 会跟随 pi 的主题和语言。
- 插件除了 PNG 和 SVG，也可以下载 JPG 和 WebP 图片。
- 某个插件因为有未保存的内容拒绝 `pi-webapp stop` 时，其他插件会继续运行，下一次停止也能正常完成。以前之后的每次停止都会失败，只能用 `stop --force`。
- 桌面应用无法连接已有服务时，会说明是响应超时还是无法连接，显示是哪一个服务（版本、启动方式、进程 ID、工作目录），并提供可以复制的准确停止命令。详见[桌面应用](./desktop#cannot-connect)。
- 文件编辑器的行号栏在横向滚动时不再变透明。
- 不会阻塞任何操作的插件恢复记录不再显示警告。

### 插件开发者

- 本地开发目录或插件包压缩文件可以替代官方托管插件。
- 托管插件可以带上 WebAssembly（需 `browser.wasm`）、绑定二进制工作区文件、设置自己的调用超时，并在工具结果里返回图片。
- 反复切换开发版本失败时，不再耗尽插件的版本额度。

## pi 0.1.53 · 2026-11-05 {#v0-1-53}

npm 版本。在 Web 启动器或桌面应用里点 **升级并重启** 即可安装。

### 亮点

- **可编辑的文件浏览器。** **工作区文件** 现在左边是预览、右边是目录树，上方的路径可以点击，在文件夹之间跳转。可以按文件名搜索，或以 `?` 开头搜索文件内容。在 Git 仓库里，修改过、新增和有冲突的文件会着色并带一个小圆点。代码、文本和 Markdown 文件在带语法高亮和查找功能的编辑器里打开，用 ⌘/Ctrl+S 保存；如果编辑期间文件在磁盘上被改动，由你选择重新加载还是覆盖。详见[文件](./workspace-tools#files)。

## 桌面构建 17 · pi 0.1.52 · 2026-11-04 {#build-17}

### 亮点

- **更清楚的错误提示。** 临时错误改为在窗口顶部弹出通知，部分带有一键修复操作，不再挤占页面布局。对话里的模型错误会拆成消息、状态码、类型和请求 ID，并提供复制详情的按钮。
- **更好看的回复。** 对话回复和文件预览使用同一个 Markdown 渲染器：支持表格等 GitHub 风格 Markdown、数学公式和代码高亮，长回复的流式显示也更流畅。
- **Arch Linux 包。** 桌面应用提供 AUR 构建脚本，详见[桌面版](./desktop#install)。

### 改进与修复

- 会话标题会用满可用宽度。
- 切换到别的会话再切回来，正在进行的回复的计时不会丢失。
- 工作区会话里的 Pi 扩展可以正常使用。
- “更新已在进行中”的错误提示已翻译。

## 桌面构建 16 · pi 0.1.39 · 2026-11-03 {#build-16}

### 亮点

- **重命名和删除会话。** 在会话的 **…** 菜单里操作。空会话不再显示在列表里。详见[重命名或删除会话](./sessions#rename-or-delete-a-chat)。
- **桌面应用的右键菜单。** 复制选中的文本，在输入框里使用常用的编辑操作，在链接上选择**复制链接地址**，在工作区或会话行上打开 **…** 操作菜单。原生菜单跟随界面语言。
- **Markdown 预览显示图片。** 工作区 Markdown 文件用相对路径引用的图片，现在会显示在预览里。
- **帮助菜单链接到本指南。** 桌面应用的 **帮助** 菜单会按你的语言打开本站。

### 改进与修复

- `pi-webapp stop --force` 可以停止自己停不下来的服务，详见[命令行](./reference/cli)。
- 浏览器拒绝剪贴板权限时，复制按钮也能用。
- 终端里选中的文字在浅色和深色主题下都看得见，⌘/Ctrl+C 可以复制。
- 重试成功后，之前的模型错误会消失。
- 插件不再能阻止应用更新，改为请你确认。

### 插件开发者

- 托管插件可以声明密钥、网络访问、定时任务、会话和工作区范围的状态。密钥可以通过在浏览器里登录 GitHub 来设置。
- 开发目录模式会自动切换到你本地的插件构建。

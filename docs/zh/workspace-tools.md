# 文件、终端与 Git

通过对话右上角常驻入口打开右侧工具栏，在「开始」页选择「工作区文件」「打开终端」或「Git 改动」。工具支持标签、调宽、分栏和全屏。侧栏「新会话」下方的「插件」可全局启停内置能力；**设置中没有另一个插件开关入口**。

## 工作区文件

逐层浏览并打开只读预览；对话中的工作区内路径链接也可打开预览。代码显示高亮和行号，Markdown 可切换预览/源码，PNG/JPEG/GIF/WebP 支持图片放大。HTML/SVG 显示源码，不执行内容。

每层最多 1,000 项，文本最多 512 KB / 10,000 行，图片最多 8 MB；不支持的二进制文件只显示提示。读取及符号链接的真实目标限于当前会话工作区。使用刷新按钮更新列表/预览。切换聊天保留标签，刷新网页会重置。

## 终端

以工作区为初始目录启动默认 shell，可交互输入、Ctrl+C 和调整尺寸。切换标签/聊天或收起侧栏不结束进程；短时断线可重连，不重放未确认输入。

- 每会话最多 8 个终端，服务最多 32 个，保留 2,000 行滚动历史。
- 关闭终端标签或停止服务会回收进程；断开的浏览器最多保留 5 分钟。刷新不恢复标签，服务重启不恢复进程。
- **使用运行 Pi 的本机用户权限，工作区不是 shell 沙箱。** 执行命令前检查路径和副作用。

## Git 改动与历史

Pi 所在机器需要 Git。变更列表最多 1,000 个文件，差异最多 512 KB / 10,000 行。列表与只读差异保留在同一面板，支持上下处改动跳转。二进制、子模块和冲突可能只显示提示。历史每次加载 50 条，支持查看提交和选择合并父提交；远端标签与领先/落后只基于本地记录，不发起 fetch。

「改动」中逐文件 **+ / −** 暂存/取消暂存；底部栏只提交已暂存内容，支持 Ctrl/Cmd+Enter。点击分支名搜索/切换本地分支，或选择「新建分支」。

::: warning 写操作是共享的
提交和切换分支要求根目录工作区；切换还要求工作树干净（含未跟踪文件）。共用工作树的已知聊天必须空闲。快照过期、锁、冲突、未完成 Git 操作、其他工作树占用等会阻止相关写操作。遵守 hooks 和签名，失败/结果不明不会自动重试。不会替你 push、fetch、强制切换、stash 或丢弃改动。
:::

只读预览的目录约束不等于终端或 Git 的权限沙箱。停用终端插件前需确认，会结束此服务全部终端；不要用它代替单标签关闭。

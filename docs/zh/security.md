# 安全与隐私

## 本地服务不是权限沙箱

访问地址含随机令牌，拥有地址可能获得本机 Agent 和工具操作能力。不要分享带令牌 URL、截图里的地址或浏览器完整地址，不要把服务直接暴露到公网。`/web` 的令牌有效期与当前 Pi 进程绑定。

终端使用运行 Pi 的用户权限，工作区只是初始目录；Agent 的工具也可能改动本机文件。只读文件预览的目录限制不能扩展理解成整个应用的沙箱。Git 写入影响共用工作树，操作前确认其他聊天与人员状态。

## 凭据与模型数据

提供方认证存放在 Pi 本地 `auth.json`，模型配置在 `models.json`，不是文档站存储。认证凭据不会返回浏览器；不要发送到聊天、上传反馈或提交 Git。发送给模型的对话/附件受所选提供方的数据政策约束；“本地界面”不等于模型推理全部离线。

## 默认错误采集（遥测）与关闭

**Web 前端和扩展端 Sentry 错误采集默认开启**，使用内置公共 DSN。默认只采集脱敏堆栈、语义操作轨迹和状态摘要，不主动采集对话、源码正文、附件、凭据、请求正文或界面录制。任意异常文本无法完美分类，不应把敏感信息放进错误消息。

在**启动 Pi/后台启动器的进程环境**中关闭：

```bash
PI_WEB_SENTRY_ENABLED=false npx pi-webapp
```

Windows PowerShell：

```powershell
$env:PI_WEB_SENTRY_ENABLED = 'false'
npx pi-webapp
```

若后台已运行，先结束任务并用原方式停止，再带环境变量启动；仅重新打开已有服务不会改变它的环境。已有 Pi 中使用 `/web` 时，在启动 `pi` 前设置同一变量。Pi 不自动读取 `.env`。桌面启动也须让实际后台继承该环境；复用外部后台时要配置外部进程，不能只刷新桌面窗口。

`PI_WEB_SENTRY_DSN` 可更换上报目标，独立前后端目标及采集边界见[现有 Sentry 专题](https://github.com/chengzhiyi/pi-webapp/blob/main/docs/sentry.md)。`PI_WEB_SENTRY_ENABLED=false` 优先于 DSN 配置。文档站本身仅提供本地搜索，本次未接入第三方搜索或分析服务。

## 安全反馈

不要在公开 Issues 中提交漏洞利用令牌或私密数据。先脱敏最小复现；没有已核实的私密安全渠道时，不在此虚构邮箱或承诺响应时限。桌面校验/签名限制见[测试指南](./desktop)，不全局关闭系统保护。

# 常见问题

对常见问题的简短回答，并附上有完整说明的页面链接。

## 通用

### pi-webapp 会取代 Pi 吗？

不会。Pi 运行代理、调用模型、执行工具并保存会话。pi-webapp 是围绕它的界面。你已有的 Pi 会话、模型、技能和扩展都会沿用。见[简介](./introduction)。

### 免费吗？需要账号吗？

pi-webapp 以 MIT 许可开源，没有自己的账号体系。模型用量由你连接的提供方计费，你需要为它准备一个凭据（[模型与提供方](./models)）。可选的 Excalidraw 插件同样不需要账号。

### 能离线使用吗？

界面本身在你的机器上运行，但第一次启动要从 npm 下载包，而且代理需要一个模型。如果你把自定义提供方指向自己机器上的模型服务，就没有任何对话数据会离开这台机器（[模型与提供方](./models#custom-provider)）。

### 支持哪些操作系统？

Web 启动器需要 Node.js 22.19 或更新版本。桌面安装包提供 macOS（Apple 芯片和 Intel）、Windows x64 和 Linux x64（[桌面版](./desktop)）。不包含 Windows ARM 和 Linux ARM。

### 为什么命令行提示是中文的？

启动器的文字还没有做本地化。[参考](./reference/cli#messages)里解释了每一条消息。浏览器界面是做了本地化的：**Pi 设置 → 通用设置 → 语言** 可以在英文和中文之间切换，默认跟随你的浏览器语言。

## 运行

### 关掉浏览器标签页会停止代理吗？

不会。在 Web 启动器和桌面应用共享的服务里，服务和它的会话都会继续运行。运行 `npx pi-webapp status` 看它是否在运行，`npx pi-webapp stop` 结束它。停止会结束所有正在运行的会话和终端（[快速开始](./getting-started#stop-and-restart)）。

### 重启之后地址为什么变了？

端口和令牌在每次服务启动时都是随机的。设置里的 **升级并重启** 是例外：它会保留两者，让页面重新连上。请用 `npx pi-webapp status` 打开当前地址。

### 能指定端口吗？{#can-i-choose-the-port}

不能。没有这个设置；服务总是在 `127.0.0.1` 上取一个空闲端口。

### 能同时运行多个服务吗？{#can-i-run-more-than-one-service}

每个 Pi 数据目录对应一个服务。要故意再启动一个，请用不同的 `PI_CODING_AGENT_DIR` 启动它。它会有自己的会话、模型和凭据，用来做干净的测试很方便（[环境变量](./reference/environment)）。

### 能用手机或另一台电脑打开吗？

不能直接打开：服务只监听 `127.0.0.1`。要访问运行在另一台机器上的服务，请通过 SSH 转发它的端口，并使用相同的端口号（[安全 → 远程机器](./security#remote-machines)）。不要把它暴露到互联网上。

### 它用的是哪个版本的 Pi？

npm 包自带一个固定的、经过测试的 Pi 版本，并用它来运行服务。它从不改动你全局安装的 Pi。在 `/web` 模式下，它则运行在你自己的 Pi 里（[在 Pi 终端里使用](./use-from-pi)）。桌面应用自带它自己的 Pi。

### 能在同一个项目上同时使用 Web 界面和 Pi 终端吗？

可以。它们共用 Pi 已保存的会话，所以你在终端里开始的会话会出现在 Web 侧栏里，反过来也一样。请避免同时从两个地方驱动同一个项目，因为两边都能编辑同一批文件。

## 你的数据

### 我的会话存在哪里？怎么删除一个？

在 `~/.pi/agent/sessions/` 下，每个会话一个文件（[文件与目录](./reference/files)）。要删除某个会话，请使用侧栏里它那一行的 **…** 按钮，选 **删除会话**。文件会被移到 `pi-web/trash/` 而不是被抹掉，把它移回去就能恢复（[会话与工作区](./sessions#rename-or-delete-a-chat)）。

### 移除工作区之后，我的文件会怎样？

什么都不会发生。它只是从侧栏里隐藏。重新添加这个目录，它就回来了（[会话与工作区](./sessions#add-and-remove-workspaces)）。

### pi-webapp 会发送遥测数据吗？

默认不会。除非你设置 `PI_WEB_SENTRY_ENABLED=true`，否则错误上报是关闭的。你的消息只会发给你选定的模型提供方，不会发给别人（[安全与隐私](./security#what-leaves-your-machine)）。

### 怎么卸载？

先停止服务（`pi-webapp stop`），然后移除你安装的东西：

```bash
npm uninstall -g pi-webapp      # 如果你是全局安装的
pi remove npm:pi-webapp         # 如果你为 /web 把它装进了 Pi
```

桌面应用的话，删除 **pi.app**（或运行 Windows 的卸载程序）。这些步骤不会动你的 Pi 数据。pi-webapp 自己的状态在 Pi 数据目录里的 `pi-web/` 文件夹；只有当你想忘掉工作区、附件、已下载的插件和更新状态时才去删它。你的会话和凭据不在它里面。除非你也想一并丢掉它们，否则不要删除整个 `~/.pi` 目录。

## 代理与安全

### 代理能推送到 GitHub 或删除文件吗？

Git 工具不能推送，但代理和终端是以你的身份运行命令的。如果你的 Shell 已经登录了 GitHub，代理就能运行 `git push`。请把代理当作一个拿着你键盘的同事：使用版本控制、审阅差异，并让密钥远离它（[安全与隐私](./security)）。

### 工作区是沙箱吗？

不是。它只是代理开始工作的位置，不是边界。

### 在共用或远程机器上安全吗？

令牌保护着服务，但任何拿到完整地址的人都能使用它，同一台机器上的其他账号也能连到这个端口。如果你不放心让同机的其他用户拥有你账号的权限，就不要在这样的机器上使用（[安全与隐私](./security)）。
